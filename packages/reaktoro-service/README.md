# reaktoro-service

多相 / 高温高压 / 燃烧爆炸平衡终态的独立微服务，承担 phreeqpython 主链之外的复杂体系（求解职责二分见 [01-Architecture.md](../../docs/01-Architecture.md) 第四节）。当前为占位镜像，不接真实求解。

## 契约（不可违反）

- **独立进程隔离**：以独立服务部署，经本机 UDS / 回环与主链通讯；主链是唯一事实源入口，两服务不并行重复求解同一体系。
- **LGPL-2.1 §6 / §4 义务**：动态链接、运行时可替换、允许逆向调试、修改版源码可得、附 LGPL 全文、显著声明。进程隔离**不免除**这些义务（见根 [NOTICE](../../NOTICE)）。
- **接口**：gRPC / protobuf（`.proto` 与生成物入库），主链按协议 JSON / protobuf 通讯。
- **可替换性**：替换服务镜像内动态链接的 `libReaktoro` 即可，主链无需重新编译；镜像随附 LGPL-2.1 全文。
