# reaktoro-service（占位）

多相 / 高温高压 / 燃烧爆炸平衡终态的独立微服务，承担 phreeqpython 主链之外的复杂体系（见 `01-Architecture.md` 第四节「求解职责二分」）。

## 本切片状态（spec-001）

**占位，不接真实求解。** 本切片只确立可替换性契约与隔离形态，避免地基阶段背负 conda 大镜像与尚未设计的 gRPC 接口。

已确立的契约（不可在后续切片违反）：

- **独立进程隔离**：以独立服务部署，经本机 UDS / 回环与主链通讯；主链是唯一事实源入口，两服务不并行重复求解同一体系。
- **LGPL-2.1 §6 / §4 义务**：动态链接、运行时可替换、允许逆向调试、修改版源码可得、附 LGPL 全文、显著声明。进程隔离**不免除**这些义务（见根 `NOTICE`）。
- **接口**：预留 gRPC / protobuf（后续切片定义 `.proto` 与生成物）；`protoc` 已在开发环境就位。
