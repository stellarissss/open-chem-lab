# docs/progress/ · 开发进度与交接

> 阶段三 DocDD 流程的**轻量留痕区**（决策依据：台账 §10，流程正文：`docs/13`）。
> 面向 AI Agent 读：结构化、精简、仅必要（3S）。这里不是企业审批台账，是「上下文压缩后能恢复现场」的指针。

| 文件 | 角色 | 谁更新 / 何时 |
|---|---|---|
| [`LAST_SESSION.md`](LAST_SESSION.md) | **会话交接**：已完成 / 未完成 / 阻塞 / 下一步 | AI 每轮收尾更新；下轮开始先读 |
| [`done/`](done/) | **执行报告**：`NNN-主题.md`，记目标 / 改动文件 / 验证证据 / 遗留 | 有实质任务时写一份；小改动只在交接文件记一行 |

## done 报告模板

```markdown
# NNN · 主题（YYYY-MM-DD）

- 目标：<这个任务要解决什么>
- 改动文件：<列出主要文件>
- 验证证据：<跑了什么、结果；未跑的说明原因（P5 无强制门禁）>
- 遗留：<未完成 / 下一步 / 已知问题>
```

> **留痕而非防护**（P2-补）：AI 可直接修订任何文档；约束是「可追溯 + 不绕过 L2 裁决」，不是禁止修改。
> **无强制门禁**（P5）：质量靠数值零错红线 + 最小充分证据 + 用户随时可打断，不靠流程闸门。
