## 一、北极星与取舍优先级

**一句话目标**：把真实化学做成一台**以物质为本体、手动操作一切、实时演化**的自由写实实验台——开源、可自托管、无会员墙；开放性、自由度与还原度对标**现实里的化学实验室**（对外商业参照口径见 `README.md`）。

全局取舍在冲突时按此顺序裁决（展开见 `01-Architecture.md` 第一节）：

1. **玩法真实与自由**：自由台面、手动操作一切、物质为本体、后果如实发生；玩法偏移是最大的错误。
2. **诚实计算**：一切数值来自实时求解——不虚构、不硬编码、来源锚定；数值错误属常规 bug，发现即修，禁止以预设数值规避计算。
3. **专业与真实**：实验室规格、真实物质与器材、溯源与适用条件、可自托管。
4. **规模**：1000+ 可验算物种为下限，长线不封顶；以前三项为前提。
5. **性能与可维护性**：自适应调度、双平台、契约先行；作为达成前四项的手段。

## 三、系统一览（让任一 Agent 一眼掌握全景）

技术选型的完整理由、许可证与职责边界见 `01-Architecture.md` 第四、五节；此处只列构成，便于建立全局心智。

**形态**：浏览器访问前后端常驻的本地服务器；**自由 2D 实验台**（写实台面 + 器材架，器材自由拖放、手动操作一切）为主视图，出版级写实 2D 美术，3D 仅分子/晶体/球棍；单机 Docker Compose 自托管，Windows + Linux 双平台。

**分层与选型**：

| 层 | 选型要点 |
|---|---|
| 表现层（浏览器） | React + Vite + Zustand + PixiJS；自由台面交互 + WASM 渲染容器内现象；3Dmol.js 分子级 3D |
| 网关与调度 | Fastify REST/WS；自适应调度（状态变化驱动重算、稳态冻结、16.7ms 帧预算动态配额、关注度分数），表现与求解解耦——009 起为必须实现的核心组件 |
| 动态定量求解 | phreeqpython 水溶液平衡主引擎；SciPy LSODA/BDF 刚性积分；chempy 对拍；Cantera 燃烧瞬态；reaktoro-service 多相/高温高压（可选微服务） |
| 事实层与内容 | `schemas/` 单一事实源 → `content/rules/` 按体系分目录 → 构建期物化 `content/materialized/`；带 source/confidence/applicability 护栏 |
| 权威数据供应链 | 构建期离线快照 → 候选池 → AI 解析解对拍 → 用户签核 → 黄金用例 → 静态参数层；运行时零网络依赖 |
| 通信契约 | `st.phenomenon.v1` 现象协议、`st.solution_speciation.v1` 物种快照等由 schema 生成类型 |

**求解范式**：维护物种表与平衡常数，倒入任意物质后由求解器联立质量作用方程与元素/电荷守恒，一次算出物种分布；真实反应由此涌现，逐体系的方程式随物种网络自动生成。这是"真实法则驱动无限组合"的技术含义，也是规模以物种数而非手写规则数计量的原因。

## 七、环境约束（开发前须知）

- **部署形态**：前后端常驻的本地服务器，本地服务器保持在线；运行期可离线于外网独立工作。
