## 一、当前阶段唯一落地的「教学相关」项：内容组织（不是教学功能）

史料台账 **9.3**「课标知识点为主 · 多版本标注」属内容组织；**现行生效口径（§9.6 E9）**已将其降为**可选检索标签**（`curriculum.optional: true`），主线改按「化学体系 / 玩法 / 器材」组织。以下字段保留为检索索引，与 9.2「不内置教学功能」不冲突：

| 落地项 | 位置 | 说明 |
|---|---|---|
| `curriculum.knowledge_points` | `design/03` 反应规则 schema | **可选检索标签**，每条真实反应可标课标知识点、学段；不参与覆盖边界 |
| `curriculum.textbooks` | 同上 | 可选标注多版本教材对应章节，不绑死单一版本 |
| `content/curriculum/` | `design/05` 目录树 | 知识点映射与教材版本标注数据（长线完善） |
| 内容覆盖顺序 | `docs/10` M2 | 按化学体系/玩法/器材组织，课标/教材仅辅助检索 |

> 这些是**给真实反应库做可选索引**，不是分步指导、测评或教师端，也不设教学功能。任何把知识点映射扩展成「教学闭环」的改动，须先提 ADR。

## 二、长线候选设计（以下全部不进 M1–M3）

> 本章以下内容保留初版设计作为愿景存档，便于将来 M4 启动时复用，但**当前不实施、不验收、不排期**。

### 2.1 设计原则（长线）

1. **不牺牲核心玩法自由度**：教学层是「叠加在实验台之上的模板与评估」，不是把玩法锁死成分步点击。
2. **不复制 NB 模板文案**：教材实验自行编写 + 参考开放教材与课标，标注来源（对标边界）。
3. **标准对接优先复用**：LTI 1.3 用 ltijs（Apache-2.0）、学习行为上报遵循 xAPI，不自己发明协议。
4. **数据自主**：自托管，学习过程数据不出校；导出开放格式。
5. **教学交给老师**：本项目提供仿真环境与可导出的过程数据，**分步纠错、评分、作业布置、班级管理由使用方教师或第三方系统承担**。

### 2.2 教学闭环候选（对标 NB「看—做—学—练—问—测」）

| 环节 | 候选功能 | 状态 |
|---|---|---|
| 看 | 步骤动画演示、微观过程慢放 / 定格 | 长线；现象指令协议 + 时间轴回放已可支撑 |
| 做 | 引导式分步实验 | 长线；任何步骤可跳过进入自由实验台 |
| 学 | 知识点卡、反应图鉴、原理交互 | **图鉴已在 M1 主链**；其余长线 |
| 练 | 配套练习、知识闯关、成就 | 长线 |
| 问 | 知识卡「为什么」 | 长线；可由规则 `source` 与 `safety.real_life_warning` 生成 |
| 测 | 实验操作在线测评、过程数据可视化 | 长线；**不进 M1–M3** |

### 2.3 教材同步实验模板（长线候选结构）

```yaml
# content/experiments/…（长线，当前不实施）
id: exp_jhs_oxygen_from_kmno4
title: 高锰酸钾分解制取氧气
curriculum:
  stage: 初中
  grade: 九年级
  textbooks: [人教版, 教科版, 苏教版, 沪科版]
  knowledge_points: [氧气的实验室制法, 催化剂, 分解反应]
steps:
  - {order: 1, action: "place", target: "app:test_tube"}
  - {order: 2, action: "add", target: "sub:kmno4_s", amount_g: 5}
  - {order: 3, action: "assemble", target: "app:gas_collection"}
safety_checks:
  - {id: "s1", wrong_action: "先熄灭酒精灯再撤导管", consequence: "水倒吸导致试管炸裂", severity: high}
observable:
  expected_effects: ["spawn_particles:mat:O2", "bubbling"]
  curves: ["temperature", "mass"]
```

- 模板只描述**步骤、器材、目标现象**，不含任何商业产品文案。
- 每个模板须绑定 `golden-cases/` 断言，CI 保证参数改动不破坏教材实验。
- **分步纠错、评分点、教师端、LTI/xAPI 对接均属长线**，当前不设计验收。

### 2.4 分步指导与操作纠错（长线）

| 机制 | 长线候选说明 |
|---|---|
| 引导模式 | 高亮下一步器材、给出提示、允许「自由探索」随时切出 |
| 实时纠错 | 监听操作事件流，匹配 `safety_checks`；错误操作**照常产生后果**（不阻止），弹出知识卡 + 慢放回放 |
| 后果解释 | 从规则 `source` / `safety.real_life_warning` / `thermo` 生成「为什么会这样」 |
| 一键重置 | 回到步骤起点，零成本反复练 |

> 「纠错不阻止错误、而是让错误后果可视化」与主链「错误操作后果」玩法一致；但**引导 / 评分 / 班级管理本身**仍属长线。

### 2.5 实验报告（长线候选；M1 已有最小版本）

M1 垂直切片已包含**最小实验报告**（操作序列、四条曲线、现象截图、反应式与来源），用于跑通全链路。以下为长线增强，**不进 M1–M3 验收**：

| 长线增强 | 数据来源 |
|---|---|
| 多参数对比（改浓度 / 温度，曲线叠加） | 时间轴 `curves` |
| 导出 Markdown / PDF / CSV | 报告模板 |
| 结论与误差讨论模板 | 模板 + 用户输入 |

### 2.6 操作测评与过程数据（长线）

```
操作事件流 → 评分规则匹配 → 过程数据可视化（长线）
```

- 事件类型：`place / add / pour / heat / ignite / power / seal / stir / filter / measure / stop`（主链已采集，供时间轴与报告使用）。
- **评分维度、教师端看板、xAPI 语句写入 LRS 均为长线**，当前只保证事件数据可导出。

### 2.7 教师端 / 学生端 / 班级（长线）

| 角色 | 长线候选功能 |
|---|---|
| 教师 | 授课演示、布置探究作业、查看班级报告与过程数据、导出成绩 |
| 学生 | 预习 / 课中 / 课后、引导实验、自由实验台、闯关与勋章 |
| 管理 | 本地账号、班级、角色权限、模板审核、数据导出与备份 |

> 台账 9.2 明确「教学工作交给使用者的老师」；本项目**不内置**上述角色功能，最多提供可导出的过程数据接口。

### 2.8 LTI 1.3 / xAPI 标准对接（长线，复用不自研）

| 标准 | 组件 | 许可 | 状态 |
|---|---|---|---|
| LTI 1.3 Advantage | `Cvmcosta/ltijs` | Apache-2.0 | 长线备选 |
| xAPI | `adlnet/xAPI-Spec` | Apache-2.0 | 长线备选 |
| H5P（可选） | `tunapanda/h5p-standalone` | MIT | 长线备选 |
| H5P core | `h5p/h5p-php-library` | **GPL-3.0** | 依台账 6.2 选型决策不纳入；仅只读参考 |

> PhET 单 HTML（GPL）与 H5P core 若将来使用，只能是**独立自托管页面**，不 import、不并入主构建产物（ADR-0005）。

## 三、正确性护栏（长线功能若启动，仍须遵守主链红线）

1. 教学模板引用的反应必须是 `confidence: verified`。
2. 每条现象在界面标注「教学近似，非实验级数据」；**数值零错红线**不因教学场景放宽。
3. 现实高危操作常驻「现实操作勿模仿」。
4. 教材模板变更需内容审核 + 黄金用例回归。
5. 内容按课标知识点组织、标注多版本教材，**不复制商业产品文案**。

## 四、长线启动条件（取代初版「M3 验收」）

教学层**不在 M1–M3 验收**。将来启动（M4 或更晚）须满足：

- [ ] 核心玩法（实验台 + 定量求解 + 物种面板 + 时间轴 + 四类好玩载体）已稳定交付；
- [ ] 1000 个完全仿真反应下限达成或接近；
- [ ] 决策者明确要求启动教学层，并逐项确认范围（台账第 2 条「玩法设计逐一询问」）；
- [ ] 新增独立 ADR，说明与「教学交给老师」裁决的关系；
- [ ] `CHARTER` 第 6 条阶段划分同步更新。

> 在此之前，本章仅为**愿景存档**，不构成排期承诺、不构成验收项。
