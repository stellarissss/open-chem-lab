## 一、内核总览：静态参数层 + 动态求解层

```
[内容层] 权威源 → AI 独立对拍 → 用户人工签核 → CI 黄金用例
    ↓ 静态已验算参数（Ka/Kb/Ksp/E°/ΔG、动力学、计量、适用条件、source/confidence）
[静态参数层 · 服务端]
    ↓ 数据驱动加载，无编译期常量表
[动态求解层 · 服务端 worker]  phreeqpython(主) / SciPy LSODA·BDF / chempy(对拍) / Cantera / pyequion2
[高级平衡 · 独立微服务]      reaktoro-service (conda + UDS/protobuf)
    ↓ 物种分布 / 平衡 / 动力学 / pH / 浓度 / 活度 / 电离度 / 热效应
[SP-1 调度层]  关注度分数 · 16.7ms 帧预算 · 事件唤醒 · 稳态冻结与缓存
    ↓ solution_speciation 快照 + 时间戳
[现象编排]  st.phenomenon.v1 指令
    ↓ 异步喂入、插值平滑
[WASM 表现层]  容器内现象固定 60fps 独立渲染
```

**历史结论保留**：早期实读 `sandspiel/crate/src/species.rs` 确认「反应硬编码在 `match` 分支、加物质要重编译 WASM」，因此**物质与反应必须数据驱动**。v2.0 中该结论的落点从「改造本地落沙网格」变为「服务端静态参数层 + 动态求解层」；Sandspiel 落沙基座随实验台范式**整体退场**（台账 6.1），不再进入产品链路。

### 为什么必须是「动态求解」而不是「静态规则表」

用户裁决：弱反应、可逆、电离、水解、**隐藏反应都要真实发生**，容器内物质与主要反应可查，否则「突变 / 加指示剂会露馅」（台账 2.2 补充）；且「一切分析必须定量，用优秀算法实时求解」（2.3 补充）。静态规则表只能播放预设现象，无法回答「此刻容器里 H⁺ 是多少」「加一滴酸后平衡怎么移动」。因此：

> **隐藏化学态 = 每容器真实维护的物种分布；粒子只是它的可视化投影。**

## 二、静态参数层（事实层）

| 字段组 | 内容 | 要求 |
|---|---|---|
| 标识 | `id`、`i18n`（中英双语物质名 / 术语 / 方程式） | UI 简中默认 + 英文可选；文档仅简体中文（台账 7.3） |
| 平衡常数 | `Ka` / `Kb` / `Ksp` / `E°` / `ΔG` / `Kw` | **定量，非近似**；带单位与温度依赖 |
| 动力学 | 速率模型、速率常数、活化能 | 如适用；由 **SciPy LSODA/BDF** 积分（自动刚性切换） |
| 热物性 | `ΔH`、cp、密度、溶解度、相变点 | 来自 chemicals / thermo / CoolProp |
| 计量 | `stoichiometry` | 守恒校验（CI） |
| 适用条件 | 温度、浓度、溶剂、离子强度、pH 范围、压强、相态、催化剂 | **必填**；解决「任意混合不可判定」 |
| 溯源性 | `source`（NIST / CRC / IUPAC / 课标附录 / 开放教材）、`confidence`、AI 对拍记录、签核人 | 台账 4.4 / 10.3 |
| 数值 | `rtol` / `atol` / `stiffness: auto` / `significance: auto` | 呼应 ADR-0008 |

**验算流程（不可跳过）**：权威源 → **AI 用独立解析解 + ChemPy / Cantera / phreeqpython 独立复算对拍** → **用户人工签核** → **黄金用例进 CI 门禁**。错了不许进沙盒；非 `verified` 不进实时玩法（台账 4.4 / 10.3）。第二复核人 = AI 独立对拍 + 用户签核（C4 销项）。黄金用例须同时校验 `sane` 与 `success`，PHREEQC `-999` 哨兵值列为非法输入。

**严格真实库边界**（台账 5.4 / 6.4）：不接受虚构物质、用户自制物质、自定义规则、MOD 或规则包工坊。「超自由」= **真实物质与器材任意组合 + 真实物理化学法则驱动的无限涌现与自由探索**。未命中明确返回「当前条件下无明显变化」并记入补体系日志；**绝不 ML 猜产物**。

## 三、动态求解层（服务端实时主计算层）

| 能力 | 实现 | 复用组件 |
|---|---|---|
| 化学平衡 / 物种分布 | 质量平衡 + 电荷平衡 + 平衡常数联立；代数直接求解 | **phreeqpython（主）**、pyequion2、chempy（对拍）；复杂多相体系路由 `reaktoro-service` |
| 弱酸碱电离 / 水解 / 缓冲 | Ka/Kb/Kw 联立，pH 与电离度实时计算 | **phreeqpython（主）**、chempy（对拍）、pyequion2 |
| 沉淀溶解 / 络合 | Ksp / 形成常数，判断沉淀生成与溶解 | **phreeqpython**（`si` / `desaturate`）、chempy（对拍）；复杂体系路由 `reaktoro-service` |
| 氧化还原 / 电化学 | E°、Nernst 方程 | Cantera、phreeqpython、自研薄层 |
| 反应动力学 | 刚性 ODE 积分，自适应步长 | **SciPy LSODA / BDF**（内置自动刚性切换）；CVODES 后置 M1 可选加速 |
| 热效应 | ΔH → 温度曲线；与物性库联动 | chemicals / thermo / CoolProp |

- **快 / 慢反应分类由数值刚性自动判定**，不人为拍 τ 阈值（C3 销项）；快体系（电离 / 水解 / 酸碱）走代数平衡直接求解，慢体系走 ODE 积分。
- **隐藏反应真实发生**：不可见反应同样进入求解，容器物种面板可查（台账 3.2）。
- **数值零错红线**：反应方向、产物、计量、守恒、平衡趋势、pH / 浓度数值必须准确（台账 3.3）。

## 四、SP-1 自适应定量调度层（详见 ADR-0008）

| 层 | 机制 | 兑现的裁决 |
|---|---|---|
| 1 · 数值自适应 | **SciPy LSODA/BDF** 局部误差估计 + `rtol`/`atol` 决定步长；内置刚性检测自动切 BDF ↔ Adams；**无硬编码阈值**（M0 实测 262 次 / 1.48ms vs RK45 42500 次 / 259ms） | 4.3「不自适应硬编码阈值」、C3、D3 |
| 2 · 算力调度 | 关注度分数 = `w1·视野内 + w2·刚被操作 + w3·有可见现象 + w4·时间轴聚焦`；高分高频高精度、低分降频 / 冻结 / 缓存；按 **16.7ms 帧预算动态配额** | 「把算力给到正在观察的过程」「不拖累进程」 |
| 3 · 表现解耦 | WASM 现象渲染固定 60fps；求解结果以快照 + 时间戳异步喂入，插值 / 外推平滑 | 「60fps 与定量求解协同」 |
| 4 · 事件唤醒 + 缓存 | 加料 / 加热 / 改参数 / pH 突变 / 时间轴跳转立即重算；稳态冻结复用缓存 | 「追求全局最优」 |

**验收口径**：焦点内数值零错；帧率恒 ≥ 60fps；焦点外算力占用随关注度单调下降；**新增体系无需改调度代码**（数据驱动）。

## 五、现象系统与表现层

| P3 | 沉淀 | Solid 粒子 + 沉降 + 浑浊度 | Ksp / 过饱和度 |

| P6 | 爆炸 / 冲击波 | 压强脉冲 + 碎片粒子 | 压强 / 能量 |
| P7 | 烟雾 | 半透明粒子 + 扩散 | 浓度 |
| P8 | 腐蚀 / 溶解 | 材质逐层消去 | 浓度 / 时间 |
| P9 | 放热升温 | 温度场 + 曲线 + 蒸汽 | ΔH |
| P10 | 吸热降温 | 温度场 + 曲线 + 结霜 | ΔH |

**实时曲线**：温度 / pH / 压强 / 质量（或浓度），横轴时间，支持多参数对比；数据**来自求解层**，不是手工编排的动画曲线。

**表现层形态**：出版级写实 2D 实验台（tikz-chemlab 输出物为主）+ 容器内 WASM 现象 + 分子 / 晶体 3D（3Dmol.js）。**无无限画布、无双视图、无落沙网格**。

## 九、正确性与红线护栏

1. 每条参数带 `source` + `confidence` + **适用条件** + AI 对拍记录 + 签核人；仅 `verified` 进沙盒。
2. **数值零错红线**：方向、产物、计量、守恒、平衡趋势、pH / 浓度数值准确；视觉夸张不触碰事实层。
3. 未命中 → `{"fallback":"no_visible_change","hint":"…"}` + 补体系日志；**不做万能反应预测**。
4. 界面常驻「教学近似，非实验级数据」「现实操作勿模仿」。
5. 参数变更走 `rule_revision`、可回滚；CI 跑黄金用例集（含弱酸电离、水解、缓冲、沉淀溶解、中和、电解）。
6. 「超自由」只在真实库与真实法则内成立；禁止虚构物质 / 用户规则 / 工坊。
7. 好玩优先但零科学性错误：已制作体系既好玩又科学，未制作者可以慢（台账 2.1）。

## 十、M1 垂直切片范围（台账 8.2）

**M1 = 一个完整体系跑通全链路**，验证架构而非堆数量：

```
实验台取器材 → 服务端动态定量求解 → 容器内 WASM 现象
             → 物种面板 → 实验报告 → 时间轴回放
```

- 必做：实验台唯一视图、写实 2D 器材、服务端求解链路（`solution_speciation`）、四类好玩载体各至少一例、四类曲线、物种面板 / 时间轴、Win + Linux 双平台最小部署、CI 黄金用例与许可证门禁。
- 不做：程序化 3D 器材（长线）、教学功能（长线）、反应数堆量（M2）、工坊 / MOD / 自定义物质（永久不做）、断网可玩（永久废弃）。
- **验收以「全链路贯通 + 数值零错 + 60fps」为准，不以反应数为准。**
