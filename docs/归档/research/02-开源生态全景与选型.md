**整体型虚拟化学实验室（NB、ChemCollective、Model ChemLab、ChemBox）全部闭源**；成熟开源项目全部落在「零件层」。因此必须走**开源链集成 + 二次开发**（`CHARTER` 第 2 条：能复用的全复用，自研只做胶水层与内容层）。

> v2.0 补充：本项目已收敛为「**实验台唯一视图 + 服务端动态定量求解 + 容器内 WASM 现象表现 + 出版级写实 2D**」，因此对「落沙引擎 / 无限画布 / 万能反应预测器」类开源项目的需求**整体消失**；选型重心转向**定量求解器链**与**写实 2D 资产**。

## 四、组件链与「自研边界」（v2.0）

```
[主资产] tikz-chemlab 输出物(写实 2D；lualatex→PDF→pdftocairo -svg→svgo) + open-lab-components(仅 UI/缩略图) + LabIcons/bioicons(署名)
   ↓ 转译 / 薄包装
[前端] React + PixiJS(容器内现象) + 3Dmol.js(分子级 3D) + SmilesDrawer/Kekule.js(结构式)
   ↓ 操作事件 / 关注度上报
[服务端 · 唯一事实源]
   gateway → SP-1 调度器 → 动态定量求解器
   (phreeqpython 主 / SciPy LSODA·BDF / chempy 对拍 / Cantera / pyequion2)
   [高级平衡] reaktoro-service (conda 镜像 + UDS/protobuf，按需路由)
   ↓ 物种分布快照 + 时间戳
[现象编排] st.phenomenon.v1 → WASM 容器内现象渲染（固定 60fps）
   ↓
[内容] 人工精校真实反应库（权威源 + AI 对拍 + 用户签核 + CI 黄金用例）
   + data-thirdparty/ord 独立仓（CC-BY-SA，只取事实性反应式）
```

**自研仅占四处**（其余全部复用）：

1. **真实反应库的参数编排与验算体系**（权威源 → AI 独立对拍 → 人工签核 → 黄金用例；开源生态无现成方案）；
2. **现象映射与 `st.phenomenon.v1` 协议**（把定量结果翻译成可渲染的现象指令，事实层与表现层解耦）；
3. **实验台产品胶水层**（器材逻辑、连接拓扑、四类好玩载体、物种面板与时间轴）；
4. **SP-1 调度集成**（关注度分数 + 帧预算配额，复用 **SciPy LSODA/BDF 自动刚性切换**与 Significance Manager 范式概念）。

> **已从自研边界删除**：Sandspiel 数据驱动改造（落沙基座退场）、本地二进制规则包编译、PubChem 上万资料卡管线、Yjs 协作、程序化 3D 器材、规则包工坊。
