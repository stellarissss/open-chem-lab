# 美术资产链调研

> 核实日期：2026-11-14 · 触发：用户指定 `tikz-chemlab`（需转换）与 `@itkdm/open-lab-components`，并授权「找更好的」。
> 方法：GitHub API 目录树枚举 + npm registry + CTAN / GitHub / npm 官方原文 + LPPL 1.3c 条款原文。
> 结论：**两个点名项目都可用，但各有一个必须处理的许可证 / 质量陷阱**；同时找到互补资产。
> **v2.0**：按台账 5.3 / 6.3 收敛为「**出版级写实 2D 主调 · tikz-chemlab 主资产 · 3D 只做分子**」，程序化 3D 器材整套方案降级长线。

## 一、点名项目 1：tikz-chemlab（LaTeX 宏包，需转换）—— **升为主资产**

| 维护者 | Aihua Wang |
| 许可证 | **LPPL-1.3c**（CTAN 页面 + GitHub README 双源确认；GitHub API 显示 NONE 是因无单独 LICENSE 文件，**不是无许可**） |
| 来源 | 是经典 [`pst-labo`](https://ctan.org/pkg/pst-labo) v2.07 的 TikZ 移植；原作者 Denis Girou / Christophe Jorssen / Manuel Luque / Herbert Voß |

### 许可证陷阱与解法（关键，已查 LPPL 1.3c 原文）

- **Clause 1**：`Activities other than distribution and/or modification of the Work are not covered by this license... In particular, the act of running the Work is not restricted...` → **运行宏包（编译）不受限制，对产物不作要求**。编译出的 PDF/SVG 是「运行输出物」，不是 Work 也不是 Derived Work，**可用于本产品（LGPL-3.0 主项目）**，我们不分发宏包源码。
- **Clause 6**（若修改源码再分发）：(a) 明确标识修改版；(b) 附变更说明或完整变更日志；(c) 不暗示原作者支持；(d) 随附完整未修改原作或获取信息。→ **改名 + 附原件 + 变更日志**。
- **Clause 3 / 7**：分发 Compiled Work 针对的是**宏包本身的编译产物**，不是用户用宏包画的图。
- **Clause 9**：以其他格式分发 Work 不解除义务 —— 提醒「把 `.tex` 整体翻译成 JS 组件再分发」仍受约束。

**确定策略（写进 ADR-0004）**：

1. **只转译编译输出物**（`.tex` → `standalone` PDF → SVG → 分层 SVG/组件）。
2. **不 fork、不修改、不随产品分发宏包源码**；转换脚本只在**构建期**从 CTAN / 上游拉取源码，产出物进 `assets/`，源码不进仓库。
3. 在 `CREDITS.md` 与 `assets/attribution/ASSETS.csv` 署名 **Aihua Wang + pst-labo 四位原作者（共五人）**，注明 LPPL-1.3c 与「仅使用编译输出物」。
4. 若未来确需改宏包，按 Clause 6 改名、附变更日志、附原始副本，放独立 `upstream/` 目录，并新增 ADR。
5. 商业化前就「LPPL 输出物商用」做法务确认（工程判断，非法律意见）。

## 二、点名项目 2：@itkdm/open-lab-components —— **仅作 UI / 缩略图（D8）**

| 项 | 核实结果 |
|---|---|
| 仓库 | [`itkdm/open-lab-components`](https://github.com/itkdm/open-lab-components) ★10（快照）· MIT · npm v0.1.1 · Node ≥18 |
| 定位 | 「面向宿主系统与 AI 客户端的 STEM 教学组件基础设施」；`components/` 是单一事实源，派生 registry / JS API / 静态站 / MCP Server |
| 规模 | **210 组件 / 化学相关 35 个**（M0 实测枚举） / zh-CN + en |
| 交付形式 | 零依赖 **HTML fragment**（`data-cmp-id` + CSS 变量如 `--cmp-size` / `--cmp-body`）、JS API（`lab.list/get/categories/readSync/mount/unmount/updateProps`）、Registry JSON、静态站、MCP tools |

### 化学相关 35 个组件（M0 实测枚举）

| 分类 | 数量 | 组件 ID 示例 |
|---|---|---|
| `chemistry/labware` | **26** | `beaker.graduated` / `test-tube` / `bunsen-burner` / `burette` / `condenser` / `crucible` / `distillation-flask` / `erlenmeyer-flask` / `funnel` / `gas-jar` / `graduated-cylinder` / `ph-beaker` 等 |
| `chemistry/reaction` | **5** | `acid-base.interactive` / `electrolysis.interactive` / `equilibrium.interactive` / `rate.interactive` / `redox.interactive` |
| `chemistry/model` | **3** | `bonding.interactive` / `molecule.ball-stick` / `periodic-table.interactive` |
| `chemistry/gas` | 1 | `ideal-gas-law.interactive` |
| `chemistry/solution` | 1 | `concentration.interactive` |

**v2.0 定位变化**：26 件器材与 tikz-chemlab 的 13 个宏高度互补，但它是**扁平 SVG / HTML fragment 风格**，与台账 5.3 定的**出版级写实**主调不完全一致。因此降为**辅资产**：只在与写实主调不冲突时使用（如交互组件、周期表），常规写实器材以 tikz-chemlab 输出物为准。使用前须做**写实一致性人工复核**（`design/04` 验收项）。

**陷阱与解法**：

- v0.1.1、★10、2026-10 才活跃 → **早期项目**，须固定版本 + 回归测试。
- 它是 **HTML fragment + CSS 变量库，不是 React 组件**：`index.js` 提供 `list/get/readSync/load`，`components/**/*.html` 为片段，SVG + 14 个 `--cmp-*` CSS 变量、内联 `<script>`。用于 UI / 缩略图时以 **CSS 变量注入或 Web Component 封装**接入，**不要把片段手工改成 JSX**；M0 实测为简笔示意风（无渐变 / 高光），与出版级写实主调冲突，故不进实验台主视图。
- ~~「React 18 StrictMode 双调用 effect / 重复 DOM」验收项作废~~：该库不是 React 组件，M0 实测已据 D8 删除此验收项。

### 关键变化：不再需要 CC0 化学器材 3D 模型

早期调研（Kenney / Quaternius / Poly Haven / Sketchfab / BlendSwap / CGTrader / TurboSquid）确认：3D 化学玻璃器皿几乎全部来自商业或逐模型授权站点，**没有可直接批量集成、许可清晰的 CC0 化学器材 GLB 包**。初版据此设计了 Three.js 程序化 3D 器材。

**v2.0 处置（台账 6.3）**：产品收敛为「**2D 写实为主、3D 只做分子 / 晶体 / 球棍模型**」后，程序化 3D 器材**降级为可选长线、不进 M1**：

- 不再需要批量器材 GLB、轮廓点集提取、`LatheGeometry` 玻璃材质调优、2D/3D 一致性维护四份成本；
- 3D 直接复用 **3Dmol.js**（成熟 BSD-3 库），零外部资产、零许可风险；
- `extract-profile.mjs`、`assets/labware-profiles/`、`packages/viewer-3d/` 器材几何部分移出主流程；若将来重启须单独提 ADR。

## 五、转换可行性结论

| 步骤 | 工具 | 可行性 | 风险 |
|---|---|---|---|
| `.tex` → standalone PDF | `pdflatex` / `lualatex` / `tectonic` | 已确认 | 需 TeX 环境（用 `texlive` Docker 镜像，双平台一致） |
| PDF → SVG | **`pdftocairo -svg`（poppler）→ svgo**（M0 实测唯一可行路径） | **M0 已实测通过** | DVI→dvisvgm 与 `dvisvgm --pdf` 双路径均失败；产物纯 `<path>`、零 `<text>` / 零外部字体、21 clipPath |
| SVG → 可动态组件 | SVGO 优化 → 拆出「液体层」→ CSS 变量 / `clipPath` 驱动液位与颜色 | 判断，M0 验证 | TikZ 输出可能把液体与玻璃合并为单路径，需拆层或 `clipPath` 兜底 |
| HTML fragment → UI / 缩略图 | CSS 变量注入或 Web Component 封装 | M0 已实测形态 | 非 React；不进写实主视图 |
| **用途边界复核** | `ASSETS.csv` 的 `used_in` 校验 | **M0 后按 D8 调整** | open-lab-components 简笔示意风与写实主调冲突 → **仅 UI / 缩略图**，不进主视图；`used_in` 出现 `apparatus/*` 即违规 |

> 具体命令、目录与脚本见 [美术资产管线设计](../design/04-美术资产管线.md)。

## 六、逐资产署名清单要求（合规落地）

`assets/attribution/ASSETS.csv` 每资产（或资产组）一条记录：

```
asset_id | 源项目 | 源 URL | 作者/机构 | 许可证 | 是否修改 | 署名文本 | 用于何处
```

必须覆盖：

- **tikz-chemlab（含 pst-labo 四作者，共五人）** + 注明「仅使用编译输出物」；
- open-lab-components（MIT）；
- LabIcons（Manon Zuurmond，CC-BY-4.0，注明改动）；
- **bioicons 每个图标**（含 Servier / DBCLS / TogoTV 原始作者与各自许可）；
- Lucide / Tabler / Iconify；
- Kenney 资产包（M0 复核后）；
- **3Dmol.js BSD-3 声明 + Bioinformatics 论文引用**；
- ORD 衍生规则（CC-BY-SA-4.0，统一独立仓 `data-thirdparty/ord/`）。

CC-BY 与 CC-BY-SA 资产在产品 About 页与图注中可见；**禁止入库** AGPL / GPLv2-only 素材、许可不明或逐模型授权资源、卡通风格器材、任何商业产品（含 NB）素材与界面设计。star 数引用须标「2026-11-14 动态快照」（F3）。
