> ⚠️ **本目录是第一、二轮调研的「原始史料」，不是现行规划。**
> 其中 `开源化学沙盒实验室_调研与二次开发方案.md` 写于决策收口之前，其结论、架构与开篇「已确认的四项决策」**已被 `docs/11-问题与决策台账.md` 系统性推翻**。
> **现行设计的唯一事实源是台账**；可执行口径以 `docs/design/`、`docs/adr/`、`docs/research/01–03`、`docs/10` 与顶层文档为准。
> 本目录内容**只作检索证据与决策溯源留存**：不得作为实现依据、不得据此提 ADR、不得引用其中的推广稿数字。

## 为什么保留

- 保存多引擎检索的原始 JSON 与官网核实记录，供第三方复核调研过程（可追溯性）。
- 保存决策收敛前的方案原貌，使台账中每一条「推翻 X → 改为 Y」都有可对照的原始出处。
- **不改动史料原文**：所有修订都在现行文档中完成，本目录仅追加归档标识与对照说明。

- 引用本目录内容时须显式标注「历史归档 · 已作废」或「检索原始史料」，不得当作现行结论。
