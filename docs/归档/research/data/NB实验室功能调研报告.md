## 二、核心功能（按能力分组）

### 1. 仿真引擎与技术底座 —— 它凭什么「真」

- **化学专用系统**：官网明确 NB化学实验有**三大系统：速率系统、化学平衡系统、压强系统**，专为初高中师生打造。
- 百科进一步列出**四大引擎 + 四大系统**：热力学引擎、重力引擎、粒子引擎、组装引擎；压力系统、速率系统、化学平衡系统、化学反应系统。App 侧宣传为「自研 8 大仿真引擎」（含物理/化学/生物 3D 建模）。
- **微观过程可视化**：3D 分子模型支持放大、缩小、旋转；分子运动、化学键断裂、电流路径等抽象过程可慢放、定格、加速观察。
- **错误操作后果可视化**：浓硫酸稀释、试管口朝上加热、电路短路等真实课堂不敢做的错误操作，可在虚拟环境安全模拟并实时纠错 —— 这是它相对「看实验视频」最本质的差别。

### 2. 实验资源库 —— 有多少、覆盖什么

- 化学产品线：**初高中近 200 个经典实验**，覆盖人教版等主流教材。
- 官网资源页按「新课标 / 教学进度使用最多 / 最新发布」排序，支持按章节、知识点检索。实测可见的资源类型包括：
  - **教材经典实验**：高锰酸钾分解制取氧气、铁丝在氧气中燃烧、水的组成、粉尘爆炸、一氧化碳还原氧化铁、二氧化碳的实验室制取与性质、测定空气里氧气的含量、质量守恒测定等；
  - **趣味实验**：黄金雨、法老之蛇、滴水生烟；
  - **拓展实验**：各类喷泉实验、碘的升华、实验室制备氨气、粗盐中硫酸根离子检验等；
  - **原理交互**：原子的结构、化学方程式的配平、元素大作战；
  - **备考内容**：期末备考大串讲 + 实验操作基础自测练习。
- App 层面（全学科合计）：**2000+ 教材同步实验**，适配人教版、教科版、苏教版、沪科版等**全国 10 大教材版本**；另有 34 大知识专题、281 节实验探究微课（后两项来自推广稿，量级供参考）。

> 口径提示：「近 200 个」是**化学单科**，「2000+」是**全学科 App 合计**，二者不矛盾。

### 3. 自由 DIY 与交互操作 —— 不止是「看动画」

- **1000+ 虚拟器材自由组合、自定义参数**，即时看到现象和结果，被称为「实验界的乐高」；试管、烧杯、酒精灯等常规器具齐备，支持自主设计教材外的实验。
- 实测打开 [NB化学实验编辑器](https://hx.nobook.com/chemical/new?moduleId=9)，界面功能项包括：**保存 / 清空 / 方程式 / 设置 / 新建实验 / 实验器材 / 实验模板 / 实验报告 / 授课演示 / 布置探究作业 / 锁定 / 画笔 / 缩放**，并内置元素周期表（A–Z 元素格）与化学方程式编辑。
- 辅助认知工具：**二维元素周期表**（常规模式 + 独创图片模式，元素配高清矢量图）、**3D 分子模型**、实验步骤动画演示（对不规范操作做分步指导）。
- 编辑器顶部有安全提示：「化学实验有风险，现实操作勿模仿」。

### 4. 教与学的闭环 —— 教师端 / 学生端

| 角色 | 功能 |
|---|---|
| **教师** | 授课演示、分享可交互云端实验、布置探究作业（学校版不限次数）、精品课件与学案、校内同步示范课、**实验操作在线测评**（学生能力、过程数据、评分可视化）、学校使用报告、教学应用培训 |
| **学生** | 课前预习 / 课中 / 课后多场景探究；「看—做—学—练—问—测」学习闭环；AI 答疑与操作自动评分、薄弱点标注；知识闯关 + 积分勋章 + 科学 RPG 游戏化激励；配套练习与模拟测；**自动生成数据曲线与实验报告**，支持对比不同参数下的实验结果 |

> 「看视频 / 做实验 / 学知识 / 做练习 / 提问题」五大模块的说法主要出自百度文库「一文读懂」类文档，官网未直接证实；但 App 官方口径的「看—做—学—练—问—测」闭环与之高度呼应，可视为同一设计思路的不同表述。

### 5. 平台、终端与同步

- **多形态**：网页版、Windows / Mac 客户端、Android / iOS App、微信小程序，并已内置到**希沃白板**（含 DIY 模块）。
- **全平台多终端一账号同步实验文件**；支持在线协作与**离线使用**（官网 FAQ 明确：下载客户端扫码后可离线登录）。
- 登录限制（官网 FAQ）：同一账号同时段只能在一台电脑登录，但可同时在电脑端 + 手机端登录；微信扫码登录与手机号登录是两个不互通的账号。
- 云端实验「可分享、可交互」，教师可推送到学生平板。

### 6. 版本与商业化（官网价格页，一手信息）

| 版本 | 实验资源 / DIY 器材 | 教学功能 |
|---|---|---|
| 免费版 | 各开放约 20% | 新手体验 |
| 个人版 | 100% + 100% | 教师备授课 |
| 学校版 | 100% + 100% | 实验探究作业、学校使用报告、专校专人服务、线上教学应用培训、在线实验测评 |
| 生态合作 | — | 专属方案 / 接口 / 授权 / 个性化支持（学习机、平台、机构、数字教辅、一体机） |

可按**科目 + 学段**分别购买；学校可先申请免费试用。

### 7. 安全价值与落地规模

- 零风险：无明火、无药剂、无高压、无易碎器材，可安全完成**高危、易燃易爆、有毒、辐射性、微观、长周期**实验；零耗材、做错一键重置、可反复操作。
- 官网口径：全国累计 **30000+ 学校、2000+ 机构**使用；人大附中为实践校与研发伙伴；曾获央视 CCTV9《育见未来》等报道。
- 2024 年 3 月，湖北襄阳樊城区获赠物理、化学、生物共 498 套 NB虚拟实验室用于初中课堂（中国教育新闻网）。

## 五、一句话总结

NB实验室（NB化学实验）是北京乐步教育旗下 NOBOOK 平台的 K12 虚拟仿真实验产品：以自研理化引擎把初高中近 200 个化学实验（含高危、微观、长周期实验）做成**可自由 DIY、参数可调、错误操作可安全重现**的交互式 3D 实验，配套元素周期表、分子模型、实验报告、授课演示、探究作业与在线操作测评，网页/客户端/App/小程序多端一账号同步；免费版开放约 20% 资源，完整功能需个人版或学校版。
