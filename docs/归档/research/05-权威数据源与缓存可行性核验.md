## 二、立项背景与判据（S1 通读的主管修正）

用户本轮明确纠正：「**主线不是中学化学，主线是好玩、严谨的化学仿真实验室**」。主管 S1 通读后发现上一轮把主线误读为「中学/教学工具」并以「常温常压水溶液」为筛选边界，据此判定气相/燃烧热化学库「与主线系统性错位」——**该解读全部错误、已作废**（台账 §9.6.0）。

据此，「真正合适的权威源」判据由项目硬约束反推，而非按数据库名气：

| 判据 | 项目硬约束推导 |
|---|---|
| **主线契合** | 仿真实验台覆盖全谱系：水溶液 + 燃烧/爆炸/高温高压/多相气相 + 电化学 + 动力学 + 安全危害；气相/燃烧库是**补位非错位** |
| **数值零错** | 必须可引用的定量权威数据（logK/ΔH/ΔG/溶解度/E°/分子式），众包近似值不合格 |
| **许可证** | 能进 LGPL-3.0 主链（PD/CC0/BSD/MIT/Apache/LGPL）最优；CC-BY-SA/ODbL 须物理隔离；**非商业/禁再分发=红线** |
| **机读 + 自托管** | 有批量下载/API/结构化文件，能离线固化，单机自托管无强制在线依赖 |
| **免计算价值** | 能物化为 ADR-0006 静态参数层，构建期一次性入库、运行时 O(1) 查表 |
| **不重复造轮子** | 已有成熟解析器/绑定/客户端直接复用 |

> 用户给的 8 个库**仅作参考**，主管主动扩展候选池（水溶液权威库、物质身份/物性、安全危害、动力学机理、光谱颜色、缓存工程轮子），逐库一级来源核实。

## 五、三组最小实测（S3，脚本 + JSON 可重跑，14/14）

归档于 [`data/s2-auth/`](data/s2-auth/)（`INDEX.json` / `RERUN.md`），均不写产品代码。

| 组 | 脚本 | 结果 | 关键结论 |
|---|---|---|---|
| 1 · 物化原型 | `test_auth_snapshot.py` | **4/4** | 4 库 852 条 log_k 抽取；wateq4f 749 条物化；NIST/WATEQ4F 溯源可追；**发现 23 个多版本反应式**；确定性 SHA-256 |
| 2 · 端点可达 | `test_auth_endpoints.py` | **5/5** | PubChem PUG-REST 200 且解析乙醇 C₂H₆O/46.07；WebBook 200（仅验算）；SRD46 入口 404 / ATcT 403 如实标受限 |
| 3 · 缓存键 | `test_auth_cachekey.py` | **5/5** | 内容寻址键确定性/键顺序无关/版本变化即失效；快照四要素完整、篡改可检出；零新中间件 |

**实测驱动的两项认知修正（L0，非裁决变更）**：
1. `phreeqpython` 自带 `phreeqc.dat` 是压力依赖精简版（仅 3 条 log_k）→ 物化主源改选 `wateq4f_PWN.dat`。
2. 23 个反应式在库内多版本共存（如 `H2O=H2O` log_k 0 与 1.51）→ 内容寻址键**必须带数据源/版本维度**，不能只用反应式名（印证 E8）。

**失败项处置留痕（docs/12 §六）**：首版快照脚本 2/4 FAIL——①NIST 溯源注释位于 log_k 行内 `#` 后、原解析只读 reaction 行；②索引用 `(db, reaction)` 作键遇多版本反应式覆盖。均修正后重跑 4/4（详见 `RERUN.md`）。

## 六、分层供应链架构（E1 / E3 / E8 / E11 落地）

```
① 权威源层（离线构建期）：USGS PHREEQC 库族 · NIST JANAF/Kinetics/46/ASD · ATcT(受限) · CAMEO(隔离)
   → 人工拉取 + 一级来源核实 + 快照固化(endpoint/license/snapshot_date/sha256)
② 候选池层（confidence: extracted，不直通）：每条带 source/confidence/applicability
   → AI 独立对拍(解析解/黄金用例) + 用户签核
③ 静态参数层（唯一事实源，confidence: verified）：版本化 YAML/JSON，复用 content/rules
   → schema 三分类 fact / presentation / safety；构建期 O(1) 查表（免计算）
④ 运行时求解层：phreeqpython / reaktoro-service / Cantera / SciPy LSODA（事实源仍是③的 ruleset）
⑤ 缓存层（复用 solve_cache，零新中间件）：内容寻址键 = 体系+条件+solver_ver+ruleset_ver
   → 失效由「数据快照版本/求解器版本/ruleset_version」三者驱动
```

**准入判据（E7）**：保留 10.3 原两条（不引入商业数据库 / 不引入精度分级），新增四条——①公共领域/宽松许可可进 LGPL 主链 ②可自托管可机读批量 ③带版本/快照日/可溯源 ④AS IS 数据须对拍签核。

**数据三类分层（E10）**：fact（计量/热力学/动力学，零错签核）· presentation（颜色/焰色/外观，可夸张但标来源）· safety（GHS/危害，严谨签核，驱动错误操作后果）。
