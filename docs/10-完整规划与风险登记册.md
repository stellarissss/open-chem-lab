## 二、核心判断（一句话版）

**没有可直接部署的开源单体虚拟化学实验室**（整体型产品全部闭源），但零件层极其成熟且许可证友好。因此走「**开源链集成 + 四处自研**」：条件化规则表与现象协议、Sandspiel 数据驱动改造、产品胶水层、人工精校内容库。目标实际**高于 NB**（上万资料卡 + 数千精校规则），靠三层分离兑现，不靠硬堆。

## 三、技术路径全景（一页看懂）

```
数据离线管线
  PubChem(≤5req/s + 批量) ─┐
  ord-data(CC-BY-SA, 分仓) ─┼→ ORDerly 清洗 → RDKit 抽 SMARTS → 教学化映射 ─┐
  人工精校 content/rules/ ──┘                                              ├→ 规则合并/冲突检测/置信度
                                                                         │   → 编译 Top-N 二进制规则包
                                                                         │   → 下发客户端 / 冷规则留服务端
浏览器（热路径 60fps, 断网可玩）
  React 双视图 ─→ rule-engine(查本地规则包) ─→ ocl.phenomenon.v1 现象指令
                ─→ sim-core(Rust→WASM, fork Sandspiel, 数据驱动材质表)
                ─→ PixiJS(2D 粒子) / R3F(3D 程序化器材) / 3Dmol.js(分子)
服务端（温/冷路径, 可裁剪）
  gateway(REST/WS) ─→ Redis 缓存 ─→ chem-worker(RDKit/Cantera/CoolProp)
                    ─→ PG + RDKit Cartridge ─→ MinIO/本地卷
美术资产
  tikz-chemlab(只转译编译输出物→SVG) + open-lab-components(薄 React 包装)
  + Lucide/LabIcons(署名)/bioicons(逐个署名)/Kenney(待复核)
  + Three.js 程序化 3D 器材（无外部模型）
部署
  Docker Compose，单机 4C8G，运行期无需外网
```
