## 二、核心判断（一句话版）

**没有可直接部署的开源单体虚拟化学实验室**（整体型产品全部闭源），但零件层极其成熟且许可证友好。因此走「**开源链集成 + 四处自研**」：真实反应库的参数编排与验算、现象映射协议、实验台产品胶水、SP-1 调度集成。

产品收敛为：**写实 2D 实验台（唯一视图）+ 服务端动态定量求解 + 容器内 WASM 现象表现 + 分子级 3D + 100% 真实已验算化学库**；以 **1000 个完全仿真反应为下限**、数值零错为红线、好玩优先；**公开点名对标并超越 NB实验室**（当前已独有 = 开源 / 自托管 / 无墙；目标超越 = 反应量 / 自由度 / 用户体验，标「规划目标 · 待达成」）。

## 三、技术路径全景（一页看懂）

```
[内容] 权威源(NIST/CRC/IUPAC/课标附录/开放教材)
   → 人工精校 → AI 独立对拍(ChemPy/Cantera) → 用户人工签核 → CI 黄金用例
   → 静态参数层（Ka/Kb/Ksp/E°/ΔG、动力学、计量、适用条件、source/confidence）
   + data-ord 独立仓（CC-BY-SA，只取事实性反应式）

[服务端 · 常驻，本地服务器，唯一事实源]
   gateway(REST/WS) → SP-1 调度器（关注度分数 · 16.7ms 帧预算 · 事件唤醒/缓存）
   → 动态定量求解器（CVODES / SciPy / ChemPy / pyequion2 / Cantera / Reaktoro 动态链接）
   → solution_speciation（分子/离子/络合/沉淀/浓度/活度/pH/电离度）
   → speciation_timeline（关键快照 + 增量事件）
   → st.phenomenon.v1 现象指令

[浏览器 · 表现层，固定 60fps]
   实验台（唯一视图，写实 2D SVG） + 容器内 WASM 现象渲染（异步快照 + 插值）
   + 物种面板 / 微观视图 / 时间轴 / 图鉴 + 3Dmol.js 分子·晶体 3D

[美术资产] tikz-chemlab 输出物（主，LPPL 只转译产物）+ open-lab-components（辅）
   + LabIcons/bioicons（逐项署名）+ ASSETS.csv

[部署] Docker Compose，前后端常驻；Win + Linux 双平台硬约束；单机/多机/Demo 延后阶段二
```

## 七、路线图与验收标准（按质量闸门，不设时间预算）

用户裁决「开发周期可以很长，知识核对与验算可以放慢」，因此全仓**不设周 / 月工期**，每个里程碑以可验收的质量闸门为准。里程碑依台账 8.2 / 8.3 / 10.1 重定义，M3 命名依台账 §8.3 登记。

| 里程碑 | 定义 | 验收闸门 |
|---|---|---|
| **M0 · 基座验证**（阶段二） | 上表 10 项验证 + 仓库骨架 + CI 门禁；含 **Win + Linux 双平台**验证 | 全部通过或产出替代方案 ADR；双平台最小部署均可起 |
| **M1 · 垂直切片**（阶段三） | **一个完整体系跑通全链路**：实验台取器材 → 服务端定量求解 → 容器内现象 → 物种面板 → 实验报告 → 时间轴回放，哪怕反应数很少 | 全链路贯通、**数值零错**、四类好玩载体落地、60fps、双平台部署；**不以堆反应数为目标** |
| **M2 · 反应覆盖扩张**（阶段三） | 按体系逐个加深，向 **1000 个完全仿真反应**下限推进；内容按课标知识点覆盖 K12、标注多版本教材 | 每个新增体系真实、定量、可玩、已验算；黄金用例全绿 |

> **全量估算已删除**：初版「6–12 人月 / 单人 8–14 个月」排期假设作废（台账 1.1）。每个里程碑都产出可独立验证的版本，不追求一次铺全量数据。
