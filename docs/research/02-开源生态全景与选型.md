## 四、组件链与「自研边界」

```
[美术] tikz-chemlab(LPPL输出物) + open-lab-components(MIT) + LabIcons(CC-BY) + Lucide(ISC)
   ↓ 转译/封装
[前端] React + PixiJS(2D粒子) + R3F/Three.js(3D器材) + 3Dmol.js(分子) + Kekule.js(结构式)
   ↓
[L1 规则] —— 自研：条件化规则表 + 现象编排 + 置信度（核心自研价值）
   ↓
[L0 引擎] fork Sandspiel(MIT)：把硬编码 match 改成数据驱动（核心二次开发）
   ↓
[L2 计算] RDKit(BSD) + Cantera(待核) + CoolProp/thermo/chemicals(MIT)
   ↓
[L3 数据] PostgreSQL + RDKit Cartridge + Redis + MinIO
   ↓
[数据源] PubChem(公开) + ORD(CC-BY-SA, 分仓) + ORDerly(MIT) + 人工精校库
```

**自研仅占四处**（其余全部复用）：
1. **条件化反应规则表 + 现象指令协议**（开源生态中无现成方案，检索 `reaction SMARTS template extraction` 返回 0 结果）
2. **Sandspiel 的数据驱动改造**（其反应逻辑硬编码在 `species.rs`，撑不到上万物质）
3. **产品胶水层**（双视图、实验台器材逻辑、错误操作后果编排、存档/图鉴/工坊）
4. **人工精校内容库**（教材实验规则，保证正确性）
