## 一、对手是谁（先厘清名称，避免设计错对象）

| 名称 | 定位 | 与本项目关系 |
|---|---|---|
| **NOBOOK 虚拟实验** | 品牌 / 平台，涵盖物理、化学、生物、小学科学 | 平台级参照 |
| **NB化学实验 / NB化学实验室 / NB仿真化学实验室** | 化学产品线，初高中，**近 200 个经典实验** | **主要对手**（用户所说的「仿真化学实验室」） |
| **NB实验室 App** | 学生移动端，小初高 12 年理科全打通，全学科 2000+ 实验 | 学段覆盖参照 |

- 开发主体：北京乐步教育科技有限公司（曾用名北京亚泰盛世科技发展有限公司），2014 年上线。
- 商业化：免费版功能有限，完整功能需购买个人版 / 学校版；学校版增加探究作业、测评、培训与服务；另有生态合作授权。
- **关键事实**：NB 不是「输入任意两种物质自动算产物」的通用反应预测器，而是**预置实验模板 + 引擎驱动的现象模拟**。这一点决定了本项目的差异化方向：以**真实物理化学法则下的动态定量求解 + 无限组合**对标其模板库。

> **口径纪律（G5）**：化学单科「近 200 个实验」是全学科 App「2000+ 实验」的子集，二者不矛盾。推广稿中的「几万种物质」「34 专题 / 281 微课」「五大模块」「隶属某教育集团」「免费版仅开放约 20%」等**未获官方证实，本分析一律不采信、不作为设计基线、不写进对外表述**。只采信一级来源（官网 / 价格页 / 资源页 / 应用商店官方描述）。

## 三、三层对标口径（统一口径 D，**对外与全仓唯一标准**）

台账 11.3 裁决：「**必须点名且『超越』，无论从事实上（不仅仅是开源，更要体现在反应量、自由度、用户体验上）还是名号上**」。8.4 只认定一项独有、G5 只采信一级来源。三者**分层共存**：

| 层次 | 内容 | 状态标注 | 依据 |
|---|---|---|---|
| **当前已独有** | **开源（LGPL-3.0）+ 可自托管 + 无会员墙** | 「已具备 / 架构性独有」 | 台账 8.4 |
| **目标超越维度** | ① **反应量**：1000 个完全仿真反应下限（含弱 / 可逆 / 电离 / 水解）vs NB 化学单科近 200 实验 ② **自由度**：真实物理化学法则下的无限组合与涌现 + 服务端动态定量求解 vs 预置模板 ③ **用户体验**：错误操作后果、容器内物种面板、时间轴回放、数值零错、出版级写实实验台 | **「规划目标 · 待达成」**，逐项标达成状态，**不冒充既成事实** | 台账 11.3 + 1.1 + 6.4 + 5.2 |
| **合规兜底** | 名号上**公开点名「对标并超越 NB实验室」**；保留「独立开源实现 · 与 NB实验室/NOBOOK 无关联、无背书」声明规避混淆；NB 侧数据**只用一级来源**，禁用未证实推广稿数字 | 强制 | 台账 7.4 + C22/C24 + G5 |

> **措辞纪律**：「超越」是**目标与可验收维度**（呼应 1.2 能力清单逐项对比），不是虚假的既成事实宣称。C24 已从主管早期「收敛为事实性对照」改判为「点名 + 目标超越维度 + 非关联声明」。

## 五、对手的软肋（我们的机会，均有依据）

1. **闭源 + 付费**：完整功能需购买会员，无法自建服务器。→ 我们开源 + 自托管 + 无会员墙（**当前已独有**）。
2. **规则黑盒**：引擎与实验内容不可审计，教师无法确认某条现象的化学依据。→ 我们每条参数带权威源、置信度、适用条件与 AI 对拍记录。
3. **模板库口径有限**：化学单科近 200 个实验，本质是预置模板。→ 我们以真实反应库 + 动态定量求解支撑自由组合与 1000 反应下限（**规划目标**）。
4. **平台锁定**：账号、云端实验、客户端绑定。→ 我们纯 Web + 自托管 + 开放存档格式。
5. **供应商锁定**：学校数据须上云。→ 我们数据留在自己的服务器，Win / Linux 均可部署。

> 早期表述「NB 无社区生产能力 → 我们做规则包工坊」已作废：台账 5.4 / 6.4 裁决**严格只做真实库、不做工坊 / MOD / 自定义物质**。差异化改由「真实法则下的无限涌现」承担。

## 六、明确的边界（合规，写进 CHARTER 与对外表述）

- 本项目与 NB/NOBOOK **无任何隶属、授权、背书或合作关系**；为**独立开源实现**。
- **不复制**其代码、美术素材、实验模板文案、界面布局、商标、图标；不提供任何破解、绕过授权、账号共享或逆向内容。
- 对标仅指**功能类别与用户体验目标的独立实现**；所有内容自行生产或取自许可证兼容的开源项目。
- 对外**公开点名「对标并超越 NB实验室」**（台账 11.3），但**「超越」限定为目标超越维度并标「规划目标 · 待达成」**；同时保留非关联声明，规避商标混淆与比较广告风险（C22 已通过改名 ST 销项）。
- 界面保留「化学实验有风险，现实操作勿模仿」「教学近似，非实验级数据」提示。
- 商业化前就**比较广告合规**做法务复核（工程判断，非法律意见）。
