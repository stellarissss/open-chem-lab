## 一、对手是谁（先厘清名称，避免设计错对象）

| 名称 | 定位 | 与本项目关系 |
|---|---|---|
| **NOBOOK 虚拟实验** | 品牌/平台，涵盖物理、化学、生物、小学科学 | 平台级参照 |
| **NB化学实验 / NB化学实验室 / NB仿真化学实验室** | 化学产品线，初高中，**近 200 个经典实验** | **主要对手**（用户所说的「仿真化学实验室」） |
| **NB实验室 App** | 学生移动端，小初高 12 年理科全打通，全学科 2000+ 实验 | 学段覆盖参照 |

- 开发主体：北京乐步教育科技有限公司（曾用名北京亚泰盛世科技发展有限公司），2014 年上线。
- 商业化：免费版约 20% 实验/器材；个人版 100%；学校版增加探究作业、测评、培训与服务；另有生态合作授权。
- **关键事实**：NB 不是「输入任意两种物质自动算产物」的通用反应预测器，而是**预置实验模板 + 引擎驱动的现象模拟**。这一点决定了我们不需要量子化学，用规则引擎即可复现其核心玩法。

> 口径提示：化学单科「近 200 个实验」是全学科 App「2000+ 实验」的子集，二者不矛盾。推广稿中的「34 专题 / 281 微课」「五大模块」「隶属翼鸥教育」未获官方证实，本分析**不采信**为设计基线。

## 三、对标 / 超越差距矩阵（本项目设计目标的量化来源）

> 「对标」= 必须达到同等功能；「超越」= 利用开源与自托管优势做到 NB 做不到或不做的。
> 优先级按 CHARTER 第 0 条：正确性 > 好玩/自由度 > 专业 > 规模 > 性能/工程。

| 能力 | NB 基线 | 本项目**对标**目标 | 本项目**超越**点 | 阶段 |
|---|---|---|---|---|
| C1 仿真引擎 | 三大系统 + 四引擎，闭源 | 速率/平衡/压强 + 热/重力/粒子/组装全覆盖，且**规则与现象数据开源可审计** | 引擎与规则解耦；可自行新增系统；现象指令协议开放，第三方可写渲染器 | M1–M2 |
| C2 实验资源 | 化学近 200 个 | 覆盖人教版/教科版/苏教版/沪科版等主流教材的经典实验 | **上万化合物资料卡 + 数千条可反应规则**；规则带置信度与来源 | M2–M3 |
| C3 自由 DIY | 1000+ 器材，参数可调 | 同等自由的器材组合与参数 | **双视图**（实验台 + 无限画布落沙）；开放自定义物质/器材/规则包导入导出 | M1 |
| C4 错误操作后果 | 有，是其最有价值特性 | 全部复现并做成**招牌玩法**：密闭加热炸裂、浓硫酸稀释飞溅、钠/钾入水爆炸、试管口朝人喷溅、酒精灯对吹 | 慢放回放 + 音效 + 后果连锁（压强→爆瓶→飞溅→起火）；**后果可参数化探索**（改浓度看爆炸阈值） | M1 |
| C5 辅助认知 | 周期表、3D 分子、分步动画 | 同等能力 | 复用 3Dmol.js / Mol* / Kekule.js，支持**从 SMILES 直接生成 3D 结构**；结构式可编辑 | M2 |

## 四、对手的软肋（我们的机会，均有依据）

1. **闭源 + 付费**：免费版仅约 20% 资源，无法自建服务器，学校数据须上云。→ 我们开源 + 自托管 + 无会员墙。
2. **规则黑盒**：引擎与实验内容不可审计，教师无法确认某条现象的化学依据。→ 我们的规则带来源与置信度。
3. **规模口径有限**：化学单科近 200 个实验，本质是模板库。→ 我们用「资料卡 / 可反应 / 表现型粒子」三层扩展到上万化合物（诚实分层，不假装每个都能反应）。
4. **平台锁定**：账号、云端实验、客户端绑定。→ 我们纯 Web + 开放存档格式 + 标准 LTI/xAPI。
5. **无社区生产能力**：内容由厂商生产。→ 我们做规则包工坊（借鉴 The Powder Toy 上千社区存档的活力，但用自有实现避开 GPL）。

## 六、可复用的验收清单（M3 结束时逐条打勾）

- [ ] 能完整演示初高中各 1 个代表实验，现象与教材一致
- [ ] 错误操作后果至少 6 类，均带慢放/音效/后果说明
- [ ] 教材同步实验可按章节/知识点检索，覆盖 ≥ 4 个教材版本
- [ ] 实验报告含温度/pH/压强/质量曲线，可导出
- [ ] 操作测评按步骤给分并可视化过程数据
- [ ] 教师端可布置作业、查看班级报告
- [ ] 断网可玩；Docker Compose 一键部署到自建服务器
- [ ] 化合物资料卡 ≥ 10000，可反应规则 ≥ 数千条，每条有来源与置信度
- [ ] 每条规则可追溯到 source；低置信规则不进实时沙盒
