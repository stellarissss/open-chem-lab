# ADR-0007 · 3D 器材程序化生成，不引入外部模型

- **状态**：已接受（2026-11-14）
- **关联**：`CHARTER` 第 1 条（2D/3D 均可）、第 4 条（美术资产）、`research/03`、`design/04`

## 背景

用户要求「2D/3D 均可」，且美术资产须来自开源项目。多引擎检索（Kenney / Quaternius / Poly Haven / Sketchfab / BlendSwap / CGTrader / TurboSquid / RenderHub / BlendKit）结果：

- 3D 化学玻璃器皿资源几乎全部集中在 **TurboSquid / CGTrader / Sketchfab / RenderHub / CGTrader 免费区** 等商业站或**逐模型授权**站点，许可混杂（有的要求署名、有的限制商用、有的禁止再分发）。
- `Poly-Haven/Public-Assets`、`KenneyNL/kenney-assets` 的 GitHub 路径均 404（前者无官方仓库，后者在官网发资产）。
- Kenney 资产包（CC0，待复核）**不含化学器材 3D 模型**，只有通用 2D/3D/UI/音效/粒子贴图。
- 结论：**没有可直接批量集成、许可清晰的 CC0 化学器材 GLB 包**。

同时，若给每件器材手工建模或采购模型，会带来：资产体积、许可管理、2D/3D 一致性维护、液位动画绑定三份成本。

## 备选

| 方案 | 判断 |
|---|---|
| A. 采购/下载商业 3D 模型 | 许可混杂、需逐个署名、可能限制商用与再分发，与开源自托管目标冲突 |
| B. 手工建模一批 CC0 器材并入库 | 可控但工作量大、维护成本高，且仍要单独处理 2D/3D 一致性 |
| **C. Three.js 程序化建模** | 零外部资产、零许可风险、与 2D 共用参数表、天然支持动态液位 |
| D. 只做 2D，放弃 3D | 违反「2D/3D 均可」 |

## 决策

**采用 C**：3D 器材由 `apparatus` 参数表 + 2D SVG 轮廓在运行时程序化生成。

| 器材 | 几何 |
|---|---|
| 烧杯 / 量筒 / 试管 / 锥形瓶 / 圆底烧瓶 / 漏斗 / 蒸发皿 / 坩埚 | `LatheGeometry`（由 SVG 轮廓采样成 profile 点集） |
| 导管 / 冷凝管 / 铁架台杆 | `TubeGeometry` / `CylinderGeometry` |
| 玻璃材质 | 统一 `MeshPhysicalMaterial`（transmission / roughness / ior 1.47） |
| 液体 | `LatheGeometry` 截取 + 裁剪面，随 `volume` 变化 |

- **单一事实源**：`apparatus.capacity_mL / mouth_diameter_mm / graduations / max_temp_K / sealable / profile` 同时驱动 2D SVG 渲染、3D 几何、容器容量计算与物理约束 —— 2D/3D 天然一致。
- **动态性免费**：液位、颜色、倾斜直接由仿真状态驱动，无需为每个状态准备模型或贴图。
- **共享仿真状态**：3D 视图只是渲染层替换，`sim-core` 状态不变（`design/02` 双视图章节）。
- **可导出**：程序化几何可导出 glTF 供社区复用（Apache-2.0），进一步丰富生态。

## 理由

1. **合规**：完全自有几何，无第三方资产许可风险（ADR-0005 白名单内）。
2. **不重复造轮子**：复用 Three.js/R3F（MIT）与已有 SVG 轮廓，不自建渲染器、不采购资产。
3. **全局总成本最低**：一套参数表管 2D/3D/物理，避免三份维护。
4. **满足「2D/3D 均可」**：且 3D 不牺牲 60fps —— 粒子沙盒仍是 WebGL2 2D 网格，3D 场景只放器材与分子（ADR-0003 性能预算）。

## 影响

- `design/04` 第四节给出几何映射与 `assets/labware-profiles/` 目录。
- `packages/viewer-3d/` 负责封装；`apparatus` schema 增加 `geometry3d.profile` 字段（`design/03` 已含）。
- 2D SVG 轮廓提取脚本 `tools/asset-pipeline/extract-profile.mjs`（M0 落地）。

## 待 M0 验证 / 未决

1. 从 tikz-chemlab / open-lab-components 的 SVG 稳定提取轮廓点集的可行性。
2. `LatheGeometry` 玻璃材质在中端设备的性能（限制场景器材数 < 30）。
3. M4 若社区贡献**确为 CC0 且署名清晰**的 GLB，可作为可选增强导入（需 ADR 补充 + `ASSETS.csv` 登记）。

## 反面约束

不得引入许可不明或逐模型授权的商业 3D 资源；不得让 3D 渲染拖垮粒子沙盒的 60fps 预算。
