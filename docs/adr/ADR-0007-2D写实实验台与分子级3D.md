# ADR-0007 · 2D 写实实验台为主，3D 只做分子 / 晶体

- **状态**：**已接受（v2.0 修订，2026-11-14）**，取代初版「3D 器材程序化生成，不引入外部模型」
- **决策者**：stellarissss（台账 5.1 / 5.3 / 6.1 / 6.3）
- **依据**：台账 5.1（C17）、5.3（C19）、6.1（C18）、6.3；`CHARTER` 第 0/1/4 条
- **关联**：ADR-0003、ADR-0004、`research/03`、`design/04`、`CREDITS.md`

## 变更史

| 版本 | 决策 | v2.0 调整原因 |
|---|---|---|
| v1.0 | 「2D/3D 均可」；因 CC0 化学器材 3D 模型稀缺，用 Three.js `LatheGeometry` / `TubeGeometry` **程序化生成全部 3D 器材**，与 2D 共用 `apparatus` 参数表 | 台账 5.1 定「**只做实验台、一切按实验室规格**」；5.3 定「**出版级写实**」推翻双层皮肤与卡通主调；6.3 裁决「**2D 写实为主、3D 只做分子**」，程序化 3D 器材**降级为可选长线、不进 M1** |

## 背景（保留调研结论）

多引擎检索（Kenney / Quaternius / Poly Haven / Sketchfab / BlendSwap / CGTrader / TurboSquid / RenderHub / BlendKit）：

- 3D 化学玻璃器皿几乎全部集中在**商业或逐模型授权站点**，许可混杂（署名 / 限制商用 / 禁止再分发）；
- `Poly-Haven/Public-Assets` 与 `KenneyNL/kenney-assets` 的 GitHub 路径均 404；Kenney 资产包不含化学器材 3D 模型；
- **结论：没有可直接批量集成、许可清晰的 CC0 化学器材 GLB 包。**

早期据此设计「程序化 3D 器材」。但 v2.0 范式收敛后，这一整套工作的**必要性消失了**：用户要的是出版级写实实验台，而 3D 器材既不符合写实 2D 主调，也不是「一切按实验室规格」的必需项；真正需要 3D 的只有分子 / 晶体 / 球棍模型。

## 备选

| 方案 | 判断 |
|---|---|
| A. 采购 / 下载商业 3D 模型 | 许可混杂、需逐个署名、可能限制商用与再分发，与开源自托管目标冲突 |
| B. 程序化生成全部 3D 器材（初版） | 在实验台范式下属于**过度设计**：额外维护 2D/3D 一致性、剖面提取、玻璃材质调优，却不是用户要的写实主视觉 |
| C. 只做 2D，完全放弃 3D | 分子 / 晶体 / 球棍模型的 3D 视图有真实教学与探索价值，不应放弃 |
| **D. 2D 写实实验台 + 分子级 3D** ✅ | 主调统一、成本最低、保留必要的 3D 能力 |

## 决策

1. **实验台为唯一主视图**（台账 5.1 / 6.1）：废弃无限画布、落沙沙盒、双视图融合、粒子画布视图。
2. **出版级写实 2D 主视觉**：以 `tikz-chemlab` 编译输出 SVG 为**主资产**，`@itkdm/open-lab-components` 为**辅资产**（ADR-0004）；废弃双层皮肤可切换、卡通游戏化主视图、Kenney 卡通器材入库。
3. **3D 只用于分子 / 晶体 / 球棍模型**：由 **3Dmol.js**（BSD-3，M0 复核）运行时生成；支持 pdb / sdf / mol2 / xyz / cif；Mol* / NGL 为备选。
4. **程序化 3D 器材降级为可选长线，不进 M1**：`tools/asset-pipeline/extract-profile.mjs`、`assets/labware-profiles/`、`packages/viewer-3d/` 的器材几何部分**移出主流程**；若将来重启，须单独提 ADR 并重新论证必要性。
5. **`apparatus` 参数表仍是单一事实源**，但用途收敛为驱动 **2D SVG 渲染、容器容量、物理约束与实验台交互**；不再承担 3D 几何生成。
6. **不为 3D 牺牲 60fps**：粒子 / 现象渲染与求解解耦由 SP-1 保证（ADR-0008），3D 场景只放分子 / 晶体，不与容器内现象渲染抢帧预算。

## 理由

1. **贴合范式**：NB 本身即实验台范式；「对标并超越」应落在反应量、自由度、数值零错与写实体验上，而不是叠加一个用户没要的 3D 器材视图。
2. **主调统一**：出版级写实 2D 是用户明确裁决（5.3），混入程序化 3D 器材会破坏视觉一致性。
3. **全局总成本最低**：省掉轮廓提取、剖面采样、玻璃材质调优、2D/3D 一致性维护四份成本；3D 收敛到分子级后，直接复用 3Dmol.js。
4. **不重复造轮子**：3D 分子视图用成熟库，2D 器材用现成开源输出物；自研只做参数表与实验台交互。
5. **仍保留 3D 能力**：「2D/3D 均可」的合理内核（分子结构可缩放旋转）没有丢失。

## 反面约束

- 不得引入许可不明或逐模型授权的商业 3D 资源。
- 不得让 3D 渲染拖垮容器内现象渲染的 60fps 预算。
- 不得在未提 ADR 的情况下把程序化 3D 器材重新拉回 M1 主流程。
- 不得把「3D 只做分子」曲解为「完全不做 3D」——微观视图 / 球棍模型是保留项。
