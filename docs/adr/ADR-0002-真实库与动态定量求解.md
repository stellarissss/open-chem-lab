## 背景

用户最初提出「NB 核心功能是仿真几万种物质、反应、器材」，但调研确认：官方口径为**化学单科近 200 个经典实验 / 1000+ DIY 器材 / App 全学科 2000+ 教材同步实验**，「几万种物质」未获官方证实（G5：只采信一级来源）。

同时有一条不可回避的科学事实：

> 「任意两种物质混合会生成什么」在化学上**不可判定** —— 取决于温度、浓度、溶剂、pH、压强、相态、催化剂、光照、时间、容器材质。

因此本项目**不做万能反应预测**。但用户裁决把要求提到了另一面：**已制作的体系必须既好玩又科学、零科学性错误**，且**弱反应、可逆、电离、水解、隐藏反应都要真实发生**（不是脚本动画）。

## 备选

| 方案 | 判断 |
|---|---|
| 纯现象级静态规则表（初版 L0/L1） | 快、可玩，但「隐藏反应」「定量平衡」「pH/浓度数值准确」无法兑现，会露馅 |
| 纯计算驱动（PubChem + ORD + ML 预测产物） | 规模大但实时性差、正确性不可全覆盖；且 ML 猜测产物违反「零科学性错误」红线 |
| **真实库 + 静态已验算参数 + 动态定量求解** ✅ | 参数来自权威源且已验算，实时求解保证平衡/动力学/pH 全部定量正确；化学事实层与表现层解耦 |

## 决策

1. **规模基线改为「反应数」**：**1000 个完全仿真反应为下限**（含弱反应、可逆、电离、水解），长线不封顶；每个新增物质必须可玩。**不设时间预算，只有质量闸门**（台账 1.1 / 2.4）。
2. **资料卡即可玩库**：凡进资料卡必须可玩；PubChem 降级为**离线候选池**，不再以「上万化合物资料卡可查」为验收目标（台账 1.3 / 2.2）。
3. **严格只做真实库**：不接受虚构物质、用户自制物质、自定义规则、MOD 或规则包工坊（台账 5.4）。「超自由」正式定义为：
   > **真实物质与器材任意组合 + 真实物理化学法则驱动的无限涌现与自由探索**（台账 6.4）。
4. **内核双层**：
   - **静态参数层**：Ka / Kb / Ksp / E° / ΔG、热物性、动力学参数、计量系数、适用条件；每条带 `source` + `confidence` + 适用条件，经权威源 + AI 独立对拍 + 用户人工签核（台账 4.4 / 10.3）。
   - **动态求解层**：服务端实时求解物种分布、平衡、动力学、pH 与浓度；复用 SUNDIALS CVODES / SciPy / ChemPy / pyequion2 / Cantera / **Reaktoro**（动态链接）。**一切分析必须定量、动态、实时**（台账 2.3 / 3.4）。
5. **隐藏化学态**：不可见反应也要发生，容器内物质与主要反应可查；每容器维护 `solution_speciation`（分子、离子、络合、沉淀、浓度、活度、电离度、反应进度），并提供**容器物种面板 + 微观视图 + 时间轴回放**（台账 3.2）。
6. **数值零错红线**：反应方向、产物、计量、守恒、平衡趋势、pH / 浓度数值必须准确；**只允许视觉夸张**（粒子密度、色彩、冲击波、慢放、音效、现象编排）；**近似规则不得进入化学事实层**（台账 2.1 / 3.3）。
7. **好玩优先但零科学性错误**：已制作体系既好玩又科学；未制作者可以慢（台账 2.1 补充）。
8. **不做万能预测**：未命中明确返回「当前条件下无明显变化」并记入补体系日志；**禁止把 ML 猜测产物塞进沙盒**。

## 理由

1. **化学诚实**：承认不可判定性，避免既不好玩也不科学的四不像，也避免虚假宣传。
2. **零科学性错误可执行**：把「正确」从口号变成「静态已验算参数 + 动态定量求解 + CI 黄金用例」的工程闸门。
3. **好玩与严谨不冲突**：事实层严格、表现层夸张，两者解耦（台账 2.1 / 3.3）。
4. **不重复造轮子**：求解器全部复用成熟开源项目（见 CREDITS §1），自研只在参数编排、现象映射与内容精校。
5. **可演进**：按体系逐个补、能力按体系逐个加深，不人为按时间尺度分层（C3 销项，数值刚性由求解器自动判定）。

## 影响

- `design/02` 定义静态参数层 + 动态求解层 + SP-1 调度；`design/03` 定义 `solution_speciation` / `speciation_timeline` / 参数 schema；`design/07` 按帧预算重写性能预算。
- ADR-0006 重写为「静态参数层 + 动态求解层」；ADR-0008 定义自适应定量调度。
- `docs/10` 路线图改为质量闸门，M2 定义为「反应覆盖扩张向 1000」。
- 早期「PubChem 导入管线」「M2 ≥10000 化合物可查」「表现型粒子 ≤512」「本地二进制规则包 Top-N」等验收标准全部作废。

## 反面约束（不可绕过）

- 任何把「未命中组合」用 ML 猜一个产物塞进沙盒的实现，都违反「零科学性错误」红线，必须先修订本 ADR。
- 任何把近似规则写进化学事实层（产物、方向、计量、平衡、pH / 浓度）的实现，同理。
- 不得引入虚构物质、用户自制物质或规则包工坊来凑「自由度」。
- 不得把「1000」解释成物质数或资料卡数；它是**完全仿真反应数下限**。
