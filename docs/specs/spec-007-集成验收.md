# spec-007 · 集成验收

## 目标

把切片 001–006 的独立能力串成一条可复现的 M1 垂直切片：实验台取器材与药品 → 倾倒组合 → 服务端定量求解 → 容器内现象 → 物种面板与时间轴回放 → 实验报告，以全链路贯通、数值零错、四类好玩载体各有实证、双平台最小部署收口 M1。

## 范围

**做**：
- 全链路贯通验收：从实验台操作到报告生成的一次连续流程，数据经 gateway 串联，web-ui 不直连求解库。
- 四类好玩载体实证：错误操作后果与涌现发现（003）、装置建造最小版（005）、物种面板与时间轴回放（004）、实验报告（006）各至少一条端到端证据。
- 双平台最小部署：Windows + Linux 的 Docker Compose 单机自托管可达，构建、许可证、文档门禁全绿。
- 报告与既有链路一致性：报告数值与求解/时间轴出口一致，三态出口如实。

**不做**（明确边界）：
- 图鉴与进度（随 M2 启动，依赖制备/提纯与纯度事实层）。
- 多体系扩张、教学功能（教学属 M4 长线）、规模扩张（M2）。
- 复杂导出、社交分享、云端同步、用户自定义内容。
- 新增或改写化学事实层数值与需签核参数；本切片只复用既有产物做验收。

## 验收标准

1. 全链路一次走通：按「求解 → 现象派生 → 时间轴回放 → 报告」顺序经 gateway 连续请求，环节间数值一致、web-ui 不直连求解库；网关响应携带协议版本头，缓存复用与 SLA 口径不回归。
2. 数值零错红线保持：黄金用例、证据自证、来源哈希锚定全绿；报告快照 pH / 离子强度 / 物种浓度与求解出口逐字段一致，时间轴曲线与时间轴产物逐字段一致，不加工、不美化、不重算。
3. 四类好玩载体各至少一条可复现证据：错误操作后果的水入酸 / 酸入水差异端到端成立（温升数值相同、飞溅指令仅水入酸派生）；装置建造最小版的取器材与倾倒操作序列进入报告；物种面板与时间轴回放同源；报告汇编数值零加工且三态出口如实。
4. 双平台最小部署可达：Linux 侧容器起服、健康检查、全链路 HTTP 可达；Windows 侧静态门禁（compose 配置、LF 行尾、路径小写、部署清单）通过；静态合规与许可证门禁通过。
5. 最小充分证据由测试产物承载（见 `03-DocDD-Process.md` 第四节证据自证原则）：新增全链路验收测试并接入 CI 强制门禁；既有 `golden-cases` / `evidence-check` / `schema-validate` / `report` / `doc-hygiene` / `license-scan` / `build` / `e2e` 不回归。

## 技术要点

遵循 `01-Architecture.md`：

- 第五节数据模型与三态出口口径：报告为 `st.report.v1` 汇编投影、不改事实层 schema；`solution_speciation` / `speciation_timeline` / `phenomenon` 契约现行字段不变。
- 第六节依赖规则与包名：验收产物落在既有 `tests/e2e/`，不新增顶层包；`web-ui` 经 gateway、不直连求解库；`protocol` 为最底层类型源。
- 第七节红线：事实零错、许可证边界、前后端常驻与双平台约束；CI 强制门禁全绿。
- 复用切片 001–006 产物：`gateway` 的 `/api/v1/{health,speciation,speciation/phenomena,heat,timeline,report}` 与 WS phenomenon 通道、`solver-worker` 的 `solve` / `derive` / `heat_directives` / `build_timeline` / `build_report`、`st.*.v1` 协议类型。验收只编排调用与一致性断言，不复制化学逻辑。

## 任务拆解

1. **全链路验收测试产物**：在 `tests/e2e/` 新增全链路测试，真实启动 gateway 与 solver-worker，经 gateway HTTP/WS 连续走通「求解 → 现象 → 时间轴 → 报告」；断言环节间数值一致、报告数值零加工、三态出口如实、四类载体证据成立、web-ui 不直连求解库（静态检查）。
2. **接入 CI 门禁**：把全链路测试接入 `.github/workflows/ci.yml`，与既有 `e2e` 并列，作为 M1 收口的强制回归。
3. **双平台与静态门禁核验**：Linux 侧 `docker compose config` 与静态合规核验、全链路 HTTP 可达；Windows 侧静态门禁（LF / 路径 / 清单）；构建、许可证、文档门禁全绿。
4. **回写与铺路**：按 `03-DocDD-Process.md` 2.3 产出三样（AGENTS 当前焦点、02 切片状态、spec-008 粗稿），查漏后跑 `doc-hygiene` 复核。
