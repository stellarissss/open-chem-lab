# spec-006 · 实验报告

## 目标

把一次实验的操作序列、求解快照、时间轴曲线与反应式汇编为可查阅的只读实验报告，每条数值原样取自求解与时间轴产物并标注来源锚点与出口状态，让「探索有沉淀、发现可回顾」在实验台上闭环；报告数据保持结构化、可复现，为后续切片的复用提供事实基础。

## 范围

**做**：
- 实验报告：由操作序列（取用/倾倒/加入顺序/求解/热效应）、物种快照、时间轴曲线与反应式汇编为结构化报告；每条数值标注来源锚点（求解出口、权威源快照哈希、对拍记录或规则集哈希），三态出口如实呈现。
- 报告只汇编、不重算化学量：数值直接取 `solution_speciation` 与时间轴产物，反应式直接引用已签核 `reaction_rule`，不在报告层改写或新建化学事实。
- 生成方式：实验台「生成报告」按钮触发，输出只读报告视图（操作序列 / 数值表 / 曲线 / 反应式 / 来源 / 出口汇总）。
- 报告数据契约：新增 `st.report.v1` 为汇编投影契约；事实层既有 schema 与求解出口一律不改。
- 报告与取数均经 gateway：web-ui 只调 `/api/v1/*`，不直连求解库；反应式与来源锚点在 `solver-worker` 侧汇编、gateway 仅代理转发，表现层只展示。

**不做**（明确边界）：
- 图鉴与进度：其「发现」判定依赖制备、提纯与纯度事实层（多体系能力），随 M2 启动；本切片只产出可供其复用的结构化报告数据，不引入图鉴卡片、发现判定或进度持久化。
- 多体系扩张、教学功能（教学属 M4 长线）。
- 复杂排版导出（PDF/打印精细化）、社交分享、云端同步、报告持久化。
- 虚构收集要素、用户自定义内容、手写虚构反应方程式。

## 验收标准

1. 报告含操作序列 + 曲线 + 反应式 + 来源四类内容；所有数值与求解出口、时间轴产物逐字段一致，不加工、不美化、不重算。
2. 每条数值携带 `source_ref` 指向来源锚点；反应式逐条回指已签核 `reaction_rule` 的 `rule_id` 与其权威源哈希；三态出口（solved / no_significant_change / degraded）在快照与出口汇总中如实呈现，降级附置信度与原因，不冒充定量结论。
3. 报告契约 `st.report.v1` 作为事实源生成 TS 类型；报告内容寻址幂等：同一操作序列与规则集版本重复生成得到同一 `report_id`，不产生新化学量。
4. 报告经 gateway 取数：web-ui 仅调用 `/api/v1/report` 等网关端点，不直连求解库；报告汇编不触碰求解科学口径，既有黄金用例与三态出口断言不回归。
5. 最小充分证据由测试产物承载（见 `03-DocDD-Process.md` 第四节证据自证原则）：报告汇编单测覆盖数值零加工、来源引用闭合、反应式回指、三态出口如实、幂等；前端构建与类型检查通过；既有 `golden-cases`/`evidence-check`/`schema-validate` 不回归。

## 技术要点

遵循 `01-Architecture.md`：
- 第五节数据模型：`speciation_timeline` / `save` / `solution_speciation` 契约不变，报告为其投影与汇编；新增 `report.v1` 仅作汇编投影契约，不进事实层主链、不新增需签核的化学参数。
- 第六节依赖规则与包名：`protocol`（schema 生成类型，最底层）、`solver-worker`（汇编，读 ruleset 与时间轴）、`gateway`（`/api/v1/report` 代理）、`web-ui`（操作日志 + 只读报告视图）按本节既有命名，不引入新顶层包。
- 数值口径：反应式由已签核 `reaction_rule` 的 `reaction.equation` 给出，来源回指 `source.sha256` 与 `ruleset_sha256`；pH/浓度/离子强度取求解活度口径原值；曲线取时间轴 `curves` 原值；来源锚点含权威源 `.dat` 快照哈希与 chempy 对拍记录。
- 复用切片 003/004/005 产物：`solver.solve()` / `timeline.build_timeline()` / `ruleset.reaction_rules` / `speciation` 的 `outcome` 三态 / `protocol` 生成的类型。

## 任务拆解

1. **`report.v1` 契约与类型**：新增 `schemas/report.v1.schema.json`（操作序列 / 快照 / 曲线 / 反应式 / 来源锚点 / 出口汇总，每条数值带 `source_ref`）；接入 `protocol` 类型生成与公共出口。
2. **报告汇编（`solver-worker`）**：新增纯汇编模块，复用 `solve()` / `build_timeline()` 与 `ruleset`，按内容寻址生成 `report_id`；不新增化学逻辑、不改科学口径。
3. **取数与只读视图**：`gateway` 新增 `/api/v1/report` 代理；`web-ui` 记录操作序列、按钮触发生成、渲染只读报告面板；报告视图不直连求解库。
4. **验证**：报告汇编单测 + 前端构建与类型检查 + 既有黄金用例/证据/schema 门禁不回归；任务内跑最小充分证据，产品级门禁由 CI 统一守门。
