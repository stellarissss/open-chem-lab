# spec-006 · 实验报告

> **状态：粗稿**。本稿只定方向与边界，细节留白；开工时在本文件就地补全为正式规格，不另建副本。

## 目标

把一次实验的操作序列、求解曲线、反应式与来源汇编为可查阅的实验报告，并以报告数据复用为图鉴与进度最小版，让「探索有沉淀、发现可回顾」在实验台上闭环。

## 范围（大略）

**做**：
- 实验报告：由操作序列（取用/倾倒/加入顺序）、物种快照、时间轴曲线与反应式汇编为结构化报告；每条数值标注来源（求解出口、对拍来源或权威快照锚点），三态出口如实呈现。
- 图鉴与进度（最小版）：以报告数据复用为图鉴卡片，记录已发现的物质/反应/现象与进度；不引入虚构收集物。
- 复用既有时间轴与现象派生输出，报告只汇编、不重算化学量。

**不做**（明确边界）：
- 多体系扩张、教学功能（教学属 M4 长线）。
- 复杂排版导出（PDF/打印精细化）、社交分享、云端同步。
- 虚构收集要素、用户自定义内容。

## 验收标准（大略，可判定）

1. 报告含操作序列 + 曲线 + 反应式 + 来源，数值原样取自求解与时间轴产物，不加工、不美化。
2. 每条结论标注来源与出口状态；降级/无明显变化如实呈现，不冒充定量结论。
3. 图鉴卡片与进度由报告数据驱动，卡片只收录真实可玩/可验算内容。
4. 报告与图鉴经 gateway 取数，web-ui 不直连求解库。
5. 最小充分证据由测试产物承载（见 `03-DocDD-Process.md` 第四节证据自证原则）。

## 技术要点

遵循 `01-Architecture.md`：
- 第五节数据模型：`speciation_timeline` / `save` 契约，报告为其投影与汇编，不改 schema。
- 第六节依赖规则：`web-ui` 经 gateway；`protocol` 为最底层类型源；复用切片 004/005 的时间轴关键帧、现象指令与实验台操作记录。
- 数值口径：反应式由已签核 `reaction_rule` 与求解物种网络给出，不手写虚构方程式；来源标注回指权威快照哈希与对拍记录。
