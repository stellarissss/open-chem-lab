# spec-008 · 反应覆盖扩张

> **状态：粗稿**。本稿只定方向与边界，细节留白；开工时在本文件就地补全为正式规格，不另建副本。

## 目标

启动 M2：在已贯通的 M1 全链路上新增一个真实化学体系的事实层（物质卡 + 条件化反应参数 + 权威源对拍签核 + 黄金用例），使求解、现象派生、物种面板、报告链路在不改架构的前提下按同一机制扩张，向 1000+ 可验算物种的规模下限迈出第一步。

## 范围（大略）

**做**：
- 新增一个真实体系：按 `01-Architecture.md` 第五节权威数据供应链，从一级来源构建候选参数，经 AI 独立解析解 + chempy/phreeqpython 交叉对拍、用户签核后进入 `content/rules/` 与物化层。
- 复用既有链路：新体系经 M1 已贯通的求解 → 现象 → 时间轴 → 报告全链路可玩、可验算，不新增顶层包。
- 黄金用例与证据自证：新体系逐条断言方向/产物/计量/守恒/平衡趋势/pH/浓度数值零错，期望标注独立来源并锚定权威源哈希。
- 图鉴与进度随本切片视情况启动（依赖制备/提纯与纯度事实层；若前置未就绪则明确留待后续切片）。

**不做**（明确边界）：
- 多体系同时扩张、教学功能（M4 长线）、自定义规则/MOD/工坊。
- 改写 M1 已签核的中和体系事实层数值；既有黄金用例与三态出口不回归。
- 复杂导出、社交分享、云端同步。

## 验收标准（大略，可判定）

1. 新体系事实层参数全部带一级来源、置信度签核、适用条件，物化幂等；非 verified 不进沙盒。
2. 黄金用例逐条数值零错（回指权威源快照哈希 + 对拍记录），证据自证门禁全绿。
3. 新体系经 gateway 全链路可玩：求解 → 现象 → 物种面板/时间轴 → 报告，报告数值与求解出口逐字段一致，三态出口如实。
4. M1 既有门禁（build / golden-cases / evidence / schema / report / e2e / 双平台部署构建）全绿、无回归。
5. 最小充分证据由测试产物承载（见 `03-DocDD-Process.md` 第四节）。

## 技术要点

遵循 `01-Architecture.md`：第五节权威数据供应链与三态出口口径（`.dat` 快照为数值真理源、JSON 卡为派生精校层，`rule_revision` 禁原地覆盖）；第六节依赖规则与包名（不新增顶层包，落在既有 `content/` + `packages/` 结构）；第七节红线（事实零错、许可证边界、CC-BY-SA 数据独立仓、CI 门禁全绿）。复用切片 001–007 的求解、时间轴、现象、报告与全链路验收产物。
