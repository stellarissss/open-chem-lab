## 约定

- 文档语言：**简体中文**，技术术语保留英文原名。
- 事实标注：调研结论须带**来源**（GitHub API / 官方 README / LICENSE 原文）；推测与工程判断须显式标注「判断」「待 M0 验证」。
- 变更规范：改 `CHARTER.md`、架构分层或许可证基线，必须新增/修改 ADR 并同步本索引。
- 状态标记：`已核实` / `待 M0 验证` / `判断` / `未采信`。
