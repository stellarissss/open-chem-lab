## 约定

- 文档语言：**简体中文**（UI 简中默认 + 英文可选；物质名 / 术语 / 方程式中英双语；文档仅简体中文）。
- 事实标注：调研结论须带**一级来源**（GitHub API / 官方 README / LICENSE 原文）；推测与工程判断须显式标注「判断」「待 M0 验证」；**star 数须标快照日期**（阶段一 `2026-11-14`、阶段二 `2026-11-15`），不把动态值当固定事实。
- 变更规范：改 `CHARTER.md`、架构分层、许可证基线或绕过台账裁决，必须新增 / 修改 ADR 并同步本索引。
- 状态标记：`已核实` / `待 M0 验证` / `判断` / `未采信` / `规划目标·待达成`。
- 编号规范：内部矛盾用 **`M-xx`** 前缀，避免与里程碑 `M0`–`M4` 混淆。
